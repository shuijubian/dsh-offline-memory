# dsh-offline-memory

给会话一份**会淡忘、能打捞**的外置记忆。上下文被压缩或清空后，它不"复活"，而是**接上**。

**当前版本：v2.3.1**

---

## 三层存储

| 层 | 文件 | 作用 |
|---|---|---|
| **底层存储** | `journal/seg-*.jsonl` | 全部会话原文（干净正文），负责"接续"与细节回溯 |
| **优化存储** | `optimized.jsonl` + `vectors/index.jsonl` | 打分压缩后的长期备份 + 向量索引，是**打捞来源**，不衰变 |
| **虚拟上下文** | `vctx.json` | 智能体的**临时工作记忆**：会衰变，删了还能从优化存储捞回 |

关键规则：

- **评分即衰变期**：低分衰变快（最短 `minDecayDays`），高分衰变慢，8 分以上永久。
- **打捞只从优化存储取**：捞回的条目进虚拟上下文并标「原本生成日期 + 打捞日期」；需要完整原文时回底层按日期/关联语句补全。
- **人设属性是独立内容**：不占容量、不衰变、不索引、分数固定 10。

## 注入规则（v2 重做）

注入块 `【记忆·不是当前对话】` 每轮按需组装，四条核心规则：

1. **上下文已有不重复注入**：精确文本比对，已有的不重复塞。
2. **同一条 24 小时内不重复**（`injectDedupHours`）：注入过就跳过，过了窗口还能再出现（防止长期记忆被永久压死）。
3. **不强迫满额**：`injectBudget` 是上限不是目标，只注入命中的部分。
4. **人设按需注入**：仅在 `persona.md` 更新 / 本轮还没注入过 / 周期（`personaInjectDays`）时出现，标签「人设修正·不是当前对话」。
5. **问句实体加权**（`entityBoost`）：问「我的狗叫什么名字」时把「它叫多宝」抬上来；候选本身是问句的不加权。
6. **实体图扩展**（`graphEnabled`）：问句里的实体顺着图带出别名/一跳邻居（"狗" → "多宝"）；太常见的扩展词自动丢弃。
7. **每轮最多取 10 条**（`retrieveLimit`）：取少了答案会被截掉。
8. **偏好独立预算**（`prefBudget`，默认 300）：偏好是固定项，不占 `injectBudget`，只有它自己超了才会丢。

> 日记不再进注入块；记忆来源只有：人设、外部源（可选）、检索命中、图片描述。

## 人设属性 + 指纹可核对

人设存在 `persona.md`，**人和智能体都能改**（`/persona` 接口）。

**指纹机制**（解决"注入了没有、注的是哪一版"）：

- 每次注入时算 `{mtime, size, hash8}`（SHA-256 前 8 位），落 `state/persona.json`。
- 注入日志 `inject.log.jsonl` 每行带 `persona` 字段。
- 注入块末尾追加一行 `（人设：N 字 · 指纹 hash8 · 时间）`，智能体可自查这轮带的是哪一版。

判定表：`时间 × 哈希` 四象限，内容变了指纹必变，只动空格/时间指纹不变。

## 图片记忆

- **只存用户发的图**（附件引用 `{type:'image', attachment}`，从 `~/.dsh/attachments/` 读字节）。
- **存原图**（哈希去重、剥 EXIF）到 `pics/<年>/<月>/v-<hash8>-<NN>.<ext>`。
- **描述**：优先视觉模型（deepseek-flash 支持图文输入）生成**差异点描述**（形状/颜色/位置/破损/水印），失败回退伴随文字，再回退占位。
- **质量闸**：描述 <8 字或含「字符/指令/编号」判失败 → 标 `unscored` 待重试，不直接入库。
- **索引**：描述存 `index.jsonl` + 向量，参与检索。
- **UI**：图片记忆弹窗直显缩略图、可标已核对、可单张删除；有「手动存图」按钮。
- **开关**：存档设置里可关「启用图片存储」（关闭不保存新图，已有图保留）。

## 实体图（v2.3.0）

解决「能认出脸，认不出名字」：向量解决"像不像"，图解决"连不连"。

```
graph/nodes.jsonl   实体节点（名字 / 别名 / 类型 / 128 维向量 / 说明）
graph/edges.jsonl   关系边（起点 / 终点 / 类型 / 出处 / 置信度 / 有效期）
```

| 能力 | 说明 |
|---|---|
| **别名** | 「狗 / 多宝 / 那只狗」归到同一实体，按任一名字都能找到 |
| **节点带向量** | 实体级语义检索，不靠字面 |
| **出处 + 置信度** | 边带 `sourceRef / sourceExcerpt / confidence / reviewStatus`（可回溯、可复核） |
| **时间范围** | 边带 `validFrom / validTo / isCurrent`；过期的边不参与检索扩展，但不删（历史可查） |

**检索怎么用**：问句里出现实体 → 顺着图带出别名和一跳邻居 → 命中这些词的条目加权。

**智能体怎么记**：`graph_note` 工具，`op=node / link / alias`。示例见 `INSTALL.md` 4.4。

> 图是**独立目录**，和 `journal` 没有任何写入关系——底层保持纯净。

## 存档迁移

**主人勾清单，插件复制数据**：

1. 设置页点「存档迁移」→ 弹出清单（9 项）：底层原文 / 优化存储 / 虚拟上下文 / 人设 / 图片记忆 / 偏好库 / 外部源 / 实体图 / 表情包。
2. 勾选要带的 → 原生目录选择器选输出目录 → 插件按清单复制。
3. 注入一条 `[迁移·存档迁移·待处理]`。
4. 智能体用 `archive_migrate` 补写 `迁移说明.md`（逐项说明用途和注意事项）；无重要内容可空置。

> 「重要会话」不在清单里——它存在 `optimized.jsonl` 里（条目带 `important: true`），勾优化存储就带走了。

## 自更新

「总览 → 更新」两个入口：

- **选择更新包更新**：选本地 zip，覆盖插件代码。
- **从 GitHub 更新**：填 `owner/repo`（默认 `shuijubian/dsh-offline-memory`）→ 下载仓库最新代码 → 覆盖。
  - 宿主直连失败时自动走国内镜像（`ghfast.top` / `ghproxy.net` / `mirror.ghproxy.com`）。

**只换代码，不碰记忆**：插件代码在 `plugins/dsh-offline-memory/`，数据在 `offline-memory/`，两者独立。更新后需重载插件生效。

## 其他功能

- **跨平台建档**：选任意文本/JSON 文件，解析 Q&A 写底层覆盖。
- **原始日志提取**：从源会话原始日志重建底层（上下文被压缩时直接用原始数据）。
- **比对底层补齐**：把还没进优化存储的条目补齐（带进度条）。
- **读档**：深度覆盖底层 + 优化 + 虚拟上下文（两次确认，不只覆盖虚拟上下文）。
- **手动存档**：补日志 + 打分 + 快照（带进度条）。
- **清理存储**：按天数清理，两层确认，清理后显示删除条数。
- **会话改名同步**：DSH 里改会话名，插件注册表自动跟上（优先用户手动改名）。

## 评分器

| 项 | 选项 | 区别 |
|---|---|---|
| 主体 | **托管**（内置规则） | 零成本零延迟、完全离线；读不懂反讽与上下文 |
| | **会话智能体接管** | 用当前会话模型打分，更懂上下文；每条多一次模型调用，失败/超时自动回退托管 |
| 模式 | **即时打分** | 进来就打，虚拟上下文立刻最新 |
| | **存档 / 唤醒时一起打分** | 先只落底层，存档或唤醒时批量补分；省调用，但之前打捞不到 |

检索三档：**混合增强**（默认，0.7 BM25 + 0.3 向量）/ **BM25** / **向量**。零依赖特征哈希向量，可换稠密模型。

## 设置页

- **总览**：总开关、测试模式、状态（含版本）、更新。
- **启用会话**：选择要启用的会话（标题 + 工作区）；每会话独立的采集/注入开关；候选只列工作区里有的、非测试会话。
- **存档设置**：全局参数 + 检索与网格 + 唤醒机制 + 会话存档操作（立即存档 / 读档 / 管理存档）+ 图片记忆。
- **评分器设置**：托管 / 接管 + 即时 / 存档时。
- **注入记录**：最近注入了什么，可重放。
- **人设属性**：心情、好感、萌属性、阵营九宫格 + 人设编辑。

## 目录（各文件职责）

```
package.json        bundle 清单；main=lib/host.js，client=client.js
cordis.patch.yml    插入加载器的一行
lib/host.js         宿主接线：采集 / 注入 / 定时 / bootstrap 调度
lib/api.mjs         设置页接口（管理/清理/读档/图片/更新/迁移）
lib/config.mjs      config.json + sessions.json；生效判定 = 总开关 AND 会话开关
lib/store.mjs       三层存储 / 衰变 / 混合检索 / 打捞 / 读档 / 清理 / 快照
lib/scoring.mjs     评分器主体（托管 / 会话接管）+ 图片描述（视觉模型）
lib/score.mjs       内置评分器（rate / mood / trait / alignment / 好感 / Q&A）
lib/image.mjs       图片记忆（存原图 / 剥 EXIF / 索引 / 提取 / 删除）
lib/decode.mjs      解会话日志（多帧 zstd → JSONL → 消息 + 标题 + 图片附件）
lib/bootstrap.mjs   首次开启全量入档（幂等、分块、可续传）
lib/vector.mjs      向量化（特征哈希，零依赖）
lib/diary.mjs       外部源/日记解析（按标题日期切段，读不到会告警）
lib/sticker.mjs     表情包库（存储/检索/配额/速查表）
lib/graph.mjs       实体图（节点/别名/关系，带出处/置信度/有效期）
lib/stat.mjs        CLI：node lib/stat.mjs [sessionId]
client.js           设置页 UI
test/smoke.mjs      冒烟测试（88 条断言）
```

## 数据布局

```
${DSH_HOME}/offline-memory/
├── config.json            配置（含 updateRepo）
├── sessions.json          会话注册表
├── inject.log.jsonl       注入记录（含 persona 指纹）
└── sessions/<key>/
    ├── journal/seg-*.jsonl   底层存储
    ├── optimized.jsonl       优化存储（长期备份 / 打捞源）
    ├── vctx.json             虚拟上下文（临时记忆）
    ├── persona.md            人设（人和智能体都能改）
    ├── pics/                 图片记忆（原图 + index.jsonl）
    ├── important.jsonl       重要会话镜像
    ├── bootstrap.json        全量入档状态机与游标
    ├── snapshots/<ts>/       回滚点
    └── state/persona.json    人设指纹
```
